# SM-1 (Server Manager) — installable phone shell

The static dashboard of a private, local dev-server manager, published here only so Android can install it as an
app (it needs HTTPS). It contains no data and no addresses. It does nothing until it's paired from the desktop
manager's phone link; it then talks to that manager directly over a private network.
